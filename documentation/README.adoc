= SmallRye Config documentation

The documentation is AsciiDoc, laid out like the Quarkus guides, and published on
https://smallrye.io/docs/smallrye-config/latest/[smallrye.io]. The site pulls it from this
repository: the `main` branch every night, and each release once it is tagged.

== Where things are

[cols="1,2"]
|===
|`src/main/asciidoc/**/*.adoc` |One page per file. The path is the page's address: `config/mappings.adoc` is published at `/docs/smallrye-config/<version>/config/mappings/`.
|`src/main/asciidoc/_nav.yml` |The sidebar: page order and sections. A new page must be added here.
|`src/main/asciidoc/_attributes.adoc` |Attributes every page includes (ids, paths, project values).
|===

== Writing a page

[source,asciidoc]
------
= Page title
:version-root: ../
include::{version-root}_attributes.adoc[]
:summary: One sentence for search engines and the page description.

Text...

== A section

Link to another page with xref:config/profiles.adoc[Profiles], or to a section of it with
xref:config/profiles.adoc#parent-profile[]. Paths in xrefs start at `src/main/asciidoc`.

[source,xml,subs="attributes+"]
----
<version>{project-version}</version>
----
------

* A page in a subdirectory sets `:version-root:` (`../` per level) before including
  `_attributes.adoc`; a page at the top includes `_attributes.adoc` directly.
* Section ids are Quarkus-style: `== Parent Profile` gets the id `parent-profile`.
* `{project-version}` is the release the documentation belongs to (set by smallrye.io).
* Admonitions: `NOTE:`, `TIP:`, `IMPORTANT:`, `WARNING:`, `CAUTION:`.

== Previewing

Pull requests that change the documentation are rendered with the smallrye.io site by the
`Documentation` workflow, which fails on a broken include or a page that does not render. The
rendered site is attached to the workflow run as the `docs-smallrye-config` artifact.

To see the documentation the way smallrye.io shows it while you write it, run from this repository:

[source,bash]
----
./mvnw -Pdocs-preview
----

and open http://localhost:8080/docs/smallrye-config/main/. Pages and included examples are published again
when you save them; refresh the page. Only Java is needed: the profile runs the
https://github.com/smallrye/smallrye.github.io/tree/develop/tools/docs[smallrye.io docs tools]
with https://www.jbang.dev[JBang]. Where JBang is installed, `jbang docs-preview@smallrye/smallrye.github.io`
does the same, and takes options such as `--port` or `--site <a smallrye.github.io checkout>`
(see `--help`).
